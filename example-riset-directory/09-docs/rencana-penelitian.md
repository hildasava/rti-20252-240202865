## 3. Catatan
Seluruh dokumen riset ini berfokus pada **Human-Computer Interaction (HCI)** dan **Cognitive Load Theory**. Data empiris diambil dari hasil pengujian 74 responden dan dianalisis menggunakan uji non-parametrik *Mann-Whitney U Test* karena data tidak terdistribusi normal.
