# 00-Outline: Manuskrip Penelitian Efisiensi Antarmuka TikTok Shop

## 1. Peta Sumber Data (Data Provenance)
* **Raw Data**: File `Data Responden Tiktokshop.xlsx` (74 observasi: 37 Kelompok 1, 37 Kelompok 2).
* **Proses Transformasi**: Analisis perbandingan *Time-on-Task* menggunakan Uji *Mann-Whitney* melalui software SPSS.
* **Output Analisis**: Hasil uji signifikansi (Asymp. Sig. < 0,001) yang tersimpan di file `Output DATA RTI.spv`.
* **Visualisasi**: Tabel perbandingan mean *Time-on-Task* dan grafik perbandingan durasi transaksi antar kondisi.

## 2. Klaim Kunci (Key Claims)
*Argumen utama yang wajib konsisten di seluruh bagian manuskrip:*
1. **Signifikansi Statistik**: Kepadatan elemen visual (*visual clutter*) secara signifikan memperlambat durasi transaksi pengguna ($p < 0,001$).
2. **Efisiensi Antarmuka**: Kondisi antarmuka *Clean* terbukti lebih efisien dengan *Mean Time-on-Task* yang lebih rendah dibandingkan kondisi *Full* (padat overlay).
3. **Kesenjangan Metodologi (*Method Gap*)**: Penelitian ini mengisi kekosongan literatur tentang pengukuran efisiensi teknis interaksi manusia-komputer pada platform *social commerce*.
4. **Validasi Gen-Z**: Karakteristik Gen-Z dalam berinteraksi dengan antarmuka dinamis TikTok Shop sangat dipengaruhi oleh kepadatan informasi visual.

## 3. Struktur Narasi Konsisten
| Bagian | Fokus Narasi |
| :--- | :--- |
| **Abstrak** | Ringkasan padat: Masalah, metode eksperimen, hasil statistik, & kesimpulan. |
| **Pendahuluan** | Masalah *visual clutter* di TikTok Shop & *method gap* penelitian UI/UX. |
| **Tinjauan Pustaka** | Prinsip usability Nielsen, *Cognitive Load*, dan *Social Commerce*. |
| **Metodologi** | Eksperimen *within-subject*, 37 responden, perangkat Samsung A23. |
| **Hasil & Analisis** | Tabel deskriptif & Uji *Mann-Whitney* (bukti perbedaan durasi). |
| **Kesimpulan** | Validasi hipotesis: Dampak visual clutter terhadap efisiensi transaksi. |

## 4. Daftar Istilah Penting
* **Visual Clutter**: Kepadatan elemen visual/overlay yang mengganggu fokus pengguna.
* **Time-on-Task**: Metrik efisiensi yang mengukur durasi penyelesaian tugas transaksi.
* **Within-Subject Design**: Desain eksperimen di mana subjek yang sama menguji semua kondisi.
* **Cognitive Load**: Beban kognitif pengguna akibat banyaknya informasi di layar.
